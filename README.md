A comprehensive data analytics solution for RiwiSport e-commerce platform, delivering actionable insights through advanced statistical analysis and interactive visualizations.

## 📊 Project Overview

This analytics engine transforms RiwiSport's PostgreSQL sales data into strategic business intelligence, featuring:

- **Statistical Analysis** - Central tendency and dispersion metrics
- **Business KPIs** - Performance indicators and benchmarks
- **Interactive Visualizations** - Data storytelling through charts
- **Strategic Insights** - Data-driven growth recommendations
